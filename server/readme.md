## 🚀 Server Setup

Follow these steps to run the backend server:

1. Navigate to the server directory:
   cd server

2. Create environment file:
   cp .env.example .env
   _(or manually rename `.env.example` to `.env`)_

3. Install dependencies:
   npm install

4. Start the development server:
   npm run dev

---

## 🌱 Seed Admin User

To create an admin user, run the following command inside the `server` folder:

npm run seed:admin
